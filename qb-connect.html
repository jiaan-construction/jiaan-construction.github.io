Connect

How an authorized administrator connects a QuickBooks Online company to JiaAn QuickBooks Bridge.

Connecting

  1. The operator runs the local authorization command on the operator-controlled computer.
  2. A browser opens Intuit's OAuth 2.0 consent screen.
  3. The administrator signs in to Intuit and selects the QuickBooks Online company to authorize.
  4. Intuit returns an authorization code to a loopback address on the local computer, which the tool exchanges for a refresh token stored in a permission-restricted local file.

No credentials are transmitted to or stored on any server operated by JIA AN Construction Pte. Ltd. Reconnecting after a revoked or expired token repeats the same steps.
