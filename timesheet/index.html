连接 Airtable

工时台直接读写你的 Airtable（03 Operations、04 Workforce、02 Commercial）。第一次在这台设备上使用，需要贴一个 Airtable 个人访问令牌。令牌只存在这台设备的浏览器里，不会上传到 GitHub 或任何其他地方。

怎么生成访问令牌（2 分钟）
  1. 打开 airtable.com/create/tokens → Create token，名字写「JIA AN 工时台」。
  2. Scopes 加三项：data.records:read、data.records:write、schema.bases:read。
  3. Access 只加三个 base：02｜Commercial & Clients、03｜Operations & Projects、04｜Workforce & HR。不要选 All workspaces。
  4. 点 Create，复制 pat 开头的那串，贴到上面。

写权限只作用于 03 Operations 的两张工时表；02 和 04 只读。令牌丢了或换电脑，回到这里重新生成即可。
