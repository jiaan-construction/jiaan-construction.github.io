JiaAn Gmail Bridge

A private desktop utility used by its operator and a small set of explicitly authorized users to read their own Gmail data, prepare drafts, and send only after explicit confirmation.

Limited purpose. This tool is not offered as a public email service. Every account must complete Google's OAuth consent flow before access is possible.

What the tool does

  • Verifies which Gmail account is connected.
  • Lists and searches messages requested by an authorized user.
  • Reads selected messages and downloads attachments only when requested.
  • Uses a separate authorization channel to prepare drafts and replies with attachments.
  • Sends an existing draft only after a fresh preview and explicit confirmation.

What the tool cannot do

  • It cannot label, mark read, archive, move messages to trash, permanently delete messages, or change Gmail settings.
  • It cannot send a newly composed message without first creating and re-checking a draft.
  • It does not use Gmail data for advertising or sale.

Data handling

The app requests gmail.readonly for reading and a separately stored gmail.compose authorization for drafts and confirmed sending. OAuth credentials are stored on an operator-controlled local computer. Gmail data is accessed or changed only in response to an authorized request. See the Privacy Policy for details.
