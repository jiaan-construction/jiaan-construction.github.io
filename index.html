JiaAn Gmail Bridge

A private desktop utility used by its operator and a small set of explicitly authorized users to access their own Gmail data through the Gmail API.

Limited purpose. This tool is not offered as a public email service. Every account must complete Google's OAuth consent flow before access is possible.

What the tool does

  • Verifies which Gmail account is connected.
  • Lists and searches messages requested by an authorized user.
  • Reads selected messages and downloads attachments only when requested.

What the tool cannot do

  • It cannot send, reply to, or forward email.
  • It cannot delete, move, label, archive, or otherwise modify email.
  • It does not use Gmail data for advertising or sale.

Data handling

The app requests only gmail.readonly. OAuth credentials are stored on an operator-controlled local computer. Gmail data is accessed only in response to an authorized request. See the Privacy Policy for details.
